Política de Privacidade – Tabuada Game

Esta Política de Privacidade descreve como os dados dos usuários são coletados, utilizados, armazenados e protegidos no aplicativo Tabuada Game, desenvolvido por Limnuz, de responsabilidade de Marcelo Lima do Nascimento.

Ao utilizar o aplicativo, o usuário concorda com as práticas descritas nesta Política.

1. Informações do Desenvolvedor

  • Nome do App: Tabuada Game
  • Desenvolvedor: Limnuz
  • Responsável: Marcelo Lima do Nascimento
  • Contato: professor.marcelo.lima25@gmail.com

2. Finalidade do Aplicativo

O Tabuada Game é um aplicativo educacional, destinado ao aprendizado e à prática de tabuada matemática.

O aplicativo é voltado ao público em geral, podendo também ser utilizado por crianças, sempre com a supervisão de pais ou responsáveis.

3. Dados Coletados

O aplicativo pode coletar e armazenar os seguintes dados pessoais fornecidos voluntariamente pelo usuário:

  • Autenticação por meio de Conta Google
  • Apelido (nome de perfil escolhido pelo usuário)
  • Foto de perfil (opcional)
  • Pontuação, desempenho e progresso no jogo

Esses dados são utilizados exclusivamente para o funcionamento das funcionalidades do aplicativo.

O aplicativo não coleta dados automaticamente, como localização, contatos, microfone, câmera ou identificadores sensíveis do dispositivo.

4. Uso de Serviços de Terceiros

O Tabuada Game utiliza serviços do Firebase, uma plataforma fornecida pelo Google, para as seguintes finalidades:

  • Autenticação de usuários (Firebase Authentication)
  • Armazenamento de dados de perfil e desempenho (Firebase Database / Firestore)

Esses serviços podem processar dados pessoais conforme suas próprias políticas de privacidade, sendo utilizados apenas para viabilizar o funcionamento do aplicativo.

O desenvolvedor não vende, não aluga e não compartilha dados pessoais com terceiros para fins comerciais ou publicitários.

5. Compartilhamento de Dados

Os dados dos usuários não são compartilhados com terceiros, exceto quando estritamente necessário para o funcionamento técnico do aplicativo por meio dos serviços do Firebase.

A pontuação e o apelido do usuário podem ser visíveis para outros usuários dentro do próprio aplicativo, exclusivamente para fins de ranking ou comparação de desempenho.

6. Armazenamento, Retenção e Exclusão de Dados

Os dados dos usuários são armazenados em servidores do Firebase.

  • Os dados são mantidos enquanto a conta do usuário estiver ativa.
  • O usuário pode solicitar a exclusão da conta e de todos os dados associados diretamente pelo aplicativo.
  • Após a exclusão, os dados são removidos de forma permanente, respeitando os prazos técnicos dos serviços utilizados.

7. Segurança das Informações

São adotadas medidas técnicas razoáveis para proteger os dados pessoais contra acesso não autorizado, alteração, divulgação ou destruição.

Ainda assim, nenhum método de transmissão ou armazenamento eletrônico é absolutamente seguro, não sendo possível garantir segurança total.

8. Privacidade de Crianças

O Tabuada Game pode ser utilizado por crianças, porém não coleta dados além do necessário para o funcionamento do aplicativo.

  • Não há anúncios.
  • Não há venda de dados.
  • Não há coleta intencional de dados sensíveis de crianças.

Pais ou responsáveis podem solicitar a exclusão da conta e dos dados da criança a qualquer momento.

9. Alterações nesta Política

Esta Política de Privacidade pode ser atualizada periodicamente. Recomenda-se que o usuário revise esta página ocasionalmente para se manter informado sobre eventuais alterações.
